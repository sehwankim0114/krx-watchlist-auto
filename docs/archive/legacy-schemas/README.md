# Legacy Action schemas

이 폴더는 과거 Custom GPT Action 스키마를 변경 이력으로만 보존합니다.

- 현재 설치용 스키마가 아닙니다.
- Custom GPT 작업 화면에 별도 Action으로 등록하지 않습니다.
- 현재 운영 원본은 `docs/custom_gpt_action_schema.yaml`입니다.
- 현재 Action 도메인은 `https://krx-live-price-ksh.diaconos.workers.dev` 한 개입니다.
- `raw.githubusercontent.com`은 Worker 내부의 공개자료 조회 경로로만 사용될 수 있으며 Custom GPT Action 도메인으로 등록하지 않습니다.
