# V8.8.0 투자종합점수 100점 세부점수 계약

버전: `2026-09-13-v8.8.0-explicit-100-point-scoring-contract`

## 1. 상태

이 계약은 사용자 승인에 따라 새로 설계된 100점 세부점수 정책이다.
기존 V6 영역 배점 `30 + 20 + 15 + 15 + 10 + 10 = 100`을 그대로 유지한다.

이 단계에서는 production 점수를 생성하지 않는다.

## 2. 설계 원칙

- V8.7.8의 실제 분포와 분위수는 보정자료로만 사용한다.
- 분위수를 자동 점수구간으로 채택하지 않는다.
- 평균값이 극단치에 왜곡되는 지표는 절대평균 대신 구간형 규칙을 사용한다.
- `legacy_market_score`를 100점으로 환산하지 않는다.
- 필수 원천이 없으면 추정·대체하지 않고 `LIMITED` 처리한다.
- 가격 과열과 기업가치는 서로 다른 영역에서 평가한다.
- 금융업은 부채비율·OCF·EV/EBITDA·PSR·순현금의 구조적 비호환성을 중립점수와 경고로 처리한다.

## 4. 핵심 새 정책

### 재무
매출·영업이익·순이익은 최근 YoY와 흑자 여부를 함께 본다.
영업이익률·ROE·부채비율은 절대 구간으로 평가한다.
영업현금흐름은 절대 금액이 아니라 `영업현금흐름 / 연매출`로 정규화한다.

### 밸류
PER·PBR은 낮을수록 기본적으로 높은 점수를 주되,
이익 악화나 낮은 ROE가 확인되면 가치함정 방지를 위해 상한을 둔다.

EV/EBITDA는
`EV = 시가총액 + 핵심 이자부채 - 현금및현금성자산`,
`EBITDA = 영업이익 + 검증된 감가상각 + 무형자산상각`
으로 계산한다.

핵심부채에는 차입금·사채만 포함하고,
리스부채와 기타금융부채는 이번 계약에서는 제외한다.

PSR은 `시가총액 / 연매출`로 계산한다.

### 성장
3년 성장률은 최근 3개 연간 원자료에서 2년 CAGR로 계산한다.
영업이익이 적자에서 흑자로 전환된 경우 CAGR을 억지 계산하지 않고 `TURNAROUND`로 분류한다.

최근 분기 가속·둔화는 최근 Q2 YoY를 직전 연간 YoY와 비교한 `증감 폭(%p)`으로 판단한다.

### 가격
1개월·3개월 흐름은 무조건 많이 오른 종목에 만점을 주지 않는다.
적당한 상승 추세에 최고점을 주고 급등 구간은 과열 부담을 반영한다.

현재위치는 기존 라벨을 다음처럼 점수화한다.

| 라벨 | 점수/5 |
|---|---:|
| 저점권 | 3.5 |
| 저점권반등초입 | 5 |
| 중간권 | 4 |
| 중상단권 | 3 |
| 상단권부담 | 1.5 |
| 고점권과열 | 0.5 |

### 거래·탄력
거래활발은 기존 5단계 라벨에 거래량 배율을 추가해 6점 범위에서 보정한다.
가격탄력은 최근 20거래일 절대등락률 기준으로
`1.5~3%`를 가장 균형적인 구간으로 본다.

### 수급
기존 V6 범위를 정확한 점수로 고정한다.

| 수급부담 | 점수/10 |
|---|---:|
| 없음 | 10 |
| 주의 | 7 |
| 경계 | 4 |
| 위험 | 1 |

## 5. 금융업 예외

공식 KRX 금융계열 benchmark ticker `1021`, `1024`, `1025`는
부채비율·영업현금흐름·EV/EBITDA·PSR·순현금의 일반기업 비교가 왜곡될 수 있다.

따라서 이 다섯 항목은 다음 중립점수를 사용하고
`SECTOR_STRUCTURAL_NONCOMPARABILITY` 경고를 남긴다.

- 부채비율 1.5/3
- 영업현금흐름 2/4
- EV/EBITDA 2/4
- PSR 1.5/3
- 순현금 1/2

## 6. 자료부족 처리

필수 입력이 없으면 해당 값을 추정하지 않는다.

`score_status = LIMITED`
`score_total = null`

부분점수 합을 100점으로 재환산하지 않는다.

## 7. production 활성화 전 필수

1. V8.8.0 정책 validator 통과
2. 112종목 dry-run
3. READY/LIMITED 비율 확인
4. 점수분포·극단치·업종편향 검증
5. 기존 V6 최종 등급구간과 충돌 확인
6. production API 별도 활성화
7. 실제 Custom GPT 화면 수동 E2E 확인

이 문서는 점수 계산 활성화가 아니라 세부점수 계약 확정본이다.
