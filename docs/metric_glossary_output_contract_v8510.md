# V8.5.10 주식표 핵심용어 자동표시 계약

버전: 2026-09-11-v8.5.10-metric-glossary-output

## 목적

V8.5.9에서 확정한 핵심용어 설명을 새 코피표·연속하락표·2.4연속하락표의 실제 Action 응답에 연결한다.

표의 14개 compact 행 구조, 종목 순서, 지표 계산값은 변경하지 않는다. 설명은 행을 늘리거나 열을 추가하지 않고 응답 최상위 메타데이터로 전달한다.

## 응답 필드

- `metric_glossary_version`: `latest/stock_table_metric_glossary_latest.json`의 버전.
- `metric_glossary_footer`: 같은 파일의 `compact_footer_text` 원문.

두 필드는 canonical JSON과 모든 compact 페이지에 동일하게 들어가야 한다.

## 표시 규칙

새 두 표를 출력할 때 모든 페이지를 합친 본표를 먼저 완성한다.

`metric_glossary_footer`가 있으면 본표 바로 아래 최소 각주 첫 줄에 원문을 정확히 1회 표시한다.

페이지가 여러 개여도 페이지마다 반복하지 않는다. 별도 장문 용어집을 자동 추가하지 않는다. 필드가 없으면 모델이 자체 설명을 만들어 대체하지 않는다.

## 설명 대상

1. 스윙
2. MA5/20/60/120
3. ATR14
4. RS 1M/3M
5. 연속등락

RS는 KOSPI 대비 상대수익률 차이이며 업종 RS가 아니다. ATR14는 예상수익률이 아니다. 스윙은 과거 확정 일봉 상태이며 미래 예측이 아니다.

## 안전장치

- compact 행은 계속 14칸이다.
- 기존 지표 계산식을 변경하지 않는다.
- `confirmed_swing_low_stop`을 생성하지 않는다.
- 투자종합점수100·실적전망 변화·업종 RS를 생성하지 않는다.
- 요청시점 현재가 실패 시 정적가격 대체를 허용하지 않는다.
- Worker 코드를 이번 단계에서 변경하지 않는다.
- compact 원본은 28,500바이트 이하, Worker 최종 응답은 30,000바이트 이하를 유지한다.
