# 공식 KRX 업종 상대강도 계약 V8.7.0

## 목적
코피표·연속하락표·2.4연속하락표의 `rs_sector_pp`를 공식 KRX 업종지수 기준으로 생성한다.
이 값은 미래 예측이나 매수·매도 신호가 아니라 같은 기간 업종 대비 과거 상대수익률 차이(%p)다.

## 공식 소스
- 종목→업종 근거: KRX 지수 구성종목
- 종목 구분 및 우선주 연결 근거: KRX 전종목기본정보의 `ISU_NM`, `KIND_STKCERT_TP_NM`
- 업종지수 수익률: 선택된 KRX 업종지수 공식 종가
- 인증은 GitHub Actions의 `KRX_ID`, `KRX_PW` repository Secrets에서만 사용한다.
- Worker·Custom GPT 런타임에는 KRX 인증정보를 저장하거나 전달하지 않는다.

## 업종 선택
1. 기본 업종 후보는 KRX 1005~1026, 1045~1047 지수다.
2. 금융(1021)과 증권(1024) 또는 보험(1025)이 함께 있으면 하위 업종을 사용한다.
3. 좁은 공식 업종이 전혀 없고 제조(1027) 구성종목이면 제조(1027)를 사용한다.
4. 직접 업종이 없는 우선주는 KRX가 우선주로 확인되고, 공식 `ISU_NM`의 종목유형 접미사를 제거한 발행회사 stem이 정확히 일치하는 보통주가 유일할 때만 그 보통주의 공식 업종을 승계한다.
5. fuzzy 이름매칭, 종목코드 접두어 추정, `sector_theme` 대체는 금지한다.
6. 모호하거나 근거가 부족하면 값 생성에 실패하며 production을 발행하지 않는다.

## 계산
`업종RS 1M/3M = 종목 공식종가 수익률 - 선택된 공식 KRX 업종지수 수익률`

- 단위: percentage points(%p)
- 종목 수익률의 기존 `start_date`를 그대로 사용한다.
- 업종지수도 동일한 `start_date`와 동일한 공식 기준일 종가를 사용한다.
- 요청시점 현재가로 재계산하지 않는다.

## 우선주 정규화
KRX 공식 종목명 끝에서만 다음 유형 접미사를 제거한다.
- `보통주`
- `우선주`
- `N우선주`
- `우선주(신형)`
- `N우선주(신형)`

## 배포 안전장치
- 모든 production 고유종목의 1M·3M 값이 준비되어야 한다.
- compact 표는 `rs_sector_pp`가 추가된 15열 스키마를 사용한다.
- 14열/15열 양쪽을 허용하는 Worker 1.4.1과 Action schema 7.1.2가 선행 배포되어야 한다.
- `investment_score_100`, `earnings_outlook_change`, `confirmed_swing_low_stop`은 계속 `자료 미제공`이다.
