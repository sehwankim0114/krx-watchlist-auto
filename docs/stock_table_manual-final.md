# 주식표 설명서

기준: 한국·미국 주식 자동화 GPT 운영 규칙
설명서 호출어: `주식표설명서`
목적: 주식표의 선택, 표시, 지표, 안전규칙을 한 문서에서 설명한다. 최신 API·규칙과 충돌하면 최신 API·규칙을 우선한다.

## 1. 30초 사용법

원하는 표 이름을 그대로 입력한다. 최신성 게이트가 정상일 때만 최신 공식 분석자료로 표시하며, 가능한 표는 요청시점 보조 현재가를 별도 조회한다. 요청현재가는 10개 → 실패분 5개 → 남은 실패분 2개 순으로 재시도하고 끝까지 실패한 종목은 ⚪로 표시한다. 정적 종가를 요청시점 현재가처럼 대신 쓰지 않는다.

전체 주식표 명령은 15개다.

1. 관종표
2. 분석표
3. 코피표
4. 코피표1개월
5. 코닥표
6. 코닥표1개월
7. 코급표
8. 월사이클표
9. 단상표
10. 환율약세표
11. 시장상태표
12. 보유종목표
13. 미관종표
14. 연속하락표
15. 2.4연속하락표

`코스피`는 코피표, `코스닥`은 코닥표로 해석한다.

## 2. 표시 읽는 법

추천 표시는 한 종목 행에서 정확히 1개만 사용한다.

- ✅: 검증된 근거가 충분하고 안전규칙상 매수 후보로 볼 수 있을 때
- 🟡: 관찰·눌림대기. 가격만으로 ✅로 올리지 않는다.
- ⚠️: 신저점·고점후하락·급락·확인된 수급위험 등 주의가 필요할 때
- 🔻: 1차 익절구간 진입 또는 상단 돌파 등 이익실현 관점이 우선될 때
- ⚪: 요청시점 현재가 확인 실패

현재가 차이 아이콘은 추천 방향이 아니다. 공식 정적 기준가격과 요청시점 가격의 차이 크기만 뜻한다.
영업손실은 종목명 왼쪽 하이픈, 확인된 수급부담은 종목명 오른쪽 언더스코어로 표시한다.

## 3. 어떤 표를 사용할지

- 관종표: 기본 관심종목 현황을 볼 때.
- 분석표: 관종표 계열 종목을 분석 관점으로 볼 때.
- 코피표: KOSPI 분석 후보 30종목을 볼 때. V8.5.3에서는 `getKospiWatchlist(table=kospi)`를 사용한다.
- 코피표1개월: KOSPI 1개월 후보군을 볼 때.
- 코닥표: KOSDAQ 분석 후보 10종목을 볼 때.
- 코닥표1개월: KOSDAQ 1개월 후보군을 볼 때.
- 코급표: KOSPI 단기 급등·상승 후보군을 볼 때.
- 월사이클표: 월간 사이클 후보를 볼 때.
- 단상표: 단기 상승 후보를 볼 때.
- 환율약세표: 환율 약세 환경 관련 후보를 볼 때.
- 시장상태표: 시장·거시·레버리지·버블 위험 등 시장 환경을 볼 때.
- 보유종목표: 사용자가 현재 대화에서 직접 제공한 보유정보를 공개 참조자료와 결합해 볼 때.
- 미관종표: S&P500 기반 미국 후보 30종목을 볼 때.
- 연속하락표: KOSPI에서 현재 연속하락 조건을 충족한 전체 종목을 볼 때. V8.5.3 `table=decliners`의 전체 페이지를 읽는다.
- 2.4연속하락표: 평균등락일수 원값 2 이상 4 미만, 현재 2~4일 하락, 큰 스윙 저점반등형, 최근 20일 신저점 제외 조건을 모두 충족한 종목을 볼 때. `table=decliners24`를 사용하며 조건충족 종목 수를 억지로 채우지 않는다.

## 4. 항목 읽는 법

주요 항목은 다음 의미로 읽는다.

- 요청시점 현재가: 정적 공식 종가와 별개로 보조 조회한 가격. 실패하면 정적가격으로 대체하지 않는다.
- 평균등락일수: 상승·하락 구간이 평균적으로 얼마나 이어지는지 보여주는 확정 일봉 지표.
- 연속등락/연속하락: 현재 진행 중인 방향·일수·누적 등락률.
- 가치매수→1차익절: 분석자료가 제공한 매수범위와 1차 이익실현 참고범위. 가격범위는 굵게 표시한다.
- 3개월 위치: 3개월 저가~고가 범위에서 요청가격이 어디에 있는지 계산한 위치. 범위를 벗어나면 0~100으로 억지 보정하지 않는다.
- 큰 스윙: 저점반등, 상승, 상승눌림, 고점후하락, 신저점, 초기반등 미확인, 횡보/미확인 등을 나타내는 과거 상태 분류이며 미래 포물선 예측이 아니다.
- MA5/20/60/120: 각 이동평균값과 5거래일 전 대비 방향. ↑ 상승, ↓ 하락, → 보합.
- 1M/3M: 확정 일봉 기준 1개월·3개월 수익률.
- 거래·탄력: 거래량/20일 평균배수, 평균 거래대금, 일중 변동폭 등을 근거로 해석한다.
- 수급·위험: 제공된 공개 수급자료의 상태·수준·근거. LIMITED는 부분자료이므로 양호하다고 단정하지 않는다.
- 기업가치·실적: 영업이익, 실적추세, PER, PBR 등 제공된 자료만 쓴다.
- 실적전망 변화: API에 없으면 `자료 미제공`.
- 상대강도: 1M/3M KOSPI 대비 %p. 업종 상대강도와 다르다.
- ATR·하루변동폭: ATR14와 20일 평균 일중고저폭. 내일의 확정 변동폭이나 예상수익률이 아니다.
- 추적손절: 확정 스윙저점 손절이 미제공이면 20일선을 참고선으로만 보여준다.
- 투자종합점수: 100점 점수가 미제공이면 다른 점수를 환산·잘라내기·임의 생성하지 않는다.

## 5. 점수·추천·주의사유 해석

V8.5.3 새 코피표·연속하락표 계열에서는 다음 네 항목이 현재 미제공일 수 있다.

- 투자종합점수100
- 실적전망 변화
- 업종 RS
- 확정 스윙저점 추적손절

미제공 항목은 반드시 `자료 미제공`으로 남긴다. 가격만 매수구간 안에 들어왔다고 ✅로 자동 승격하지 않는다. 정적 위험과 요청가격 판단이 다르면 더 보수적인 표시를 사용한다.

## 6. 여러 표 연결 방법

시장 전체를 먼저 보려면 `시장상태표`로 환경을 확인한 뒤 목적에 맞는 후보표를 본다.

예:
- 시장 환경 → 시장상태표
- KOSPI 기본 후보 → 코피표
- 최근 하락 후 반등 후보 → 연속하락표 또는 2.4연속하락표
- 단기 상승 후보 → 단상표
- 월간 반복 흐름 → 월사이클표
- 실제 보유 포지션 점검 → 보유종목표

표끼리 종목이 겹친다고 해서 자동으로 추천강도가 올라가는 것은 아니다. 각 표의 선별목적과 위험근거를 함께 본다.

## 7. 꼭 기억할 원칙

1. 최신 공식자료 표시는 `api_sync_ok`, `official_fresh_now`, `safe_to_analyze_as_latest`가 모두 true일 때만 허용한다.
2. 새 코피표·연속하락표는 지연·빌드 불일치·페이지 불완전이면 구형 표로 대체하지 않는다.
3. 연속하락표는 모든 페이지를 동일 `source_build_id`로 고정해 전체 조회한다.
4. 요청현재가는 10→5→2 재시도 후에도 실패하면 ⚪이며 정적가격으로 대체하지 않는다.
5. 평균등락·스윙·MA·수익률·RS·ATR은 확정 일봉 지표이므로 장중가격으로 다시 계산하지 않는다.
6. 요청가격으로 다시 계산하는 것은 현재위치·가격구간·최종 판단 표시다.
7. 미제공 점수·전망·업종RS·확정 손절을 임의로 만들지 않는다.
8. 20일선은 보장된 손절가격이 아니다.
9. 보유종목 수량·평균매수가·현금/신용은 Action 인수·GitHub·공개 API·로그·Knowledge에 저장하지 않는다.
10. 투자 판단 참고자료이며 확정적 매수·매도 지시가 아니다.

## 8. 주요 용어

- BOTTOM_REBOUND: 큰 스윙 저점 이후 반등 상태
- UPTREND: 상승 상태
- UPTREND_PULLBACK: 상승 중 눌림
- TOP_DECLINE: 큰 스윙 고점 이후 하락
- NEW_LOW: 최근 신저점
- EARLY_REBOUND_UNCONFIRMED: 초기 반등이나 확인 부족
- SIDEWAYS_OR_UNCONFIRMED: 횡보 또는 방향 미확인
- ATR14: Wilder 방식 14기간 평균진폭
- RS: 기준지수 대비 상대수익률 차이
- LIMITED: 일부 자료만 제공되어 강한 판단을 할 수 없는 상태
- source_build_id: 여러 페이지를 같은 빌드에서 읽기 위한 데이터 식별자
- confirmed_basis_date: 공식 분석자료 기준일
