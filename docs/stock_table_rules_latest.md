# 주식표 최신 개선형 규칙

## 1. 기본 원칙

이 문서는 사용자의 모든 국내 주식 분석표 작성 기준이다. 메모리, 예전 대화, 예전 파일, 예전 표 형식과 충돌할 경우 이 문서를 우선한다.

주식표 요청어는 다음과 같다.

* 관종표
* 분석표
* 코피표
* 코피표1개월
* 코닥표
* 코닥표1개월
* 코급표
* 월사이클표
* 단상표
* 환율약세표
* 시장상태표

사용자가 “코스피 줘”라고 하면 코피표 요청으로 이해한다.
사용자가 “코스닥 줘”라고 하면 코닥표 요청으로 이해한다.
“코종표”라는 표현은 더 이상 쓰지 않고 코닥표로 통일한다.

모든 주식표는 기본적으로 최신 개선형으로 작성한다.

표 상단에는 반드시 아래 항목을 분리 표시한다.

* 자동화 실행일
* 분석자료 기준일
* 현재가 기준시점
* 시간외 반영 여부
* 분석범위

분석자료는 요청 시점에 확인 가능한 GitHub 자동화 KRX 공식 최신 자료를 기준으로 한다.
현재가는 가능하면 요청 시점 최신가로 보정한다.

장중이면 장중 현재가를 사용한다.
장마감 후에는 당일 정규장 종가 또는 실제 확보된 시간외단일가 최종가를 사용한다.
주말·휴장일에는 직전 거래일 종가를 사용한다.
시간외단일가는 실제 자동화나 별도 확인으로 확보된 경우에만 반영한다.
확인하지 못했으면 “정규장 종가 기준 / 시간외단일가 미반영”이라고 표시한다.

## 2. 추천표시 규칙

추천표시는 다음 4가지를 사용한다.

* ✅ = 투자적격·우선검토
* 🟡 = 관찰·눌림대기
* ⚠️ = 주의
* 🔻 = 현재 매수 부적합

영업손실 기업은 추천표시 왼쪽에 `-` 하이픈을 붙인다.
수급부담·저유동성·오버행·유상증자·CB/BW/EB·보호예수 해제·대량매도·블록딜·대주주 매도·주요주주변동·자사주처분·최대주주변경 등은 추천표시 오른쪽에 `_` 언더바를 붙인다.

예시는 다음과 같다.

* `✅ 삼성전자`
* `✅_ 리노공업`
* `-🟡 삼성SDI`
* `-⚠️_ 종목명`

표시의미 설명에서는 `-`와 `_`를 반드시 백틱 코드표시로 감싸고, 각각 하이픈/언더바라고 글자로 설명한다.

`-`가 붙은 종목은 영업손실 때문에 왜 주의가 필요한지 점수·추천·주의사유 칸에 구체적으로 적는다.

`_`가 붙은 종목은 “수급확인 필요”라고만 쓰지 않고, 수급부담 칸 또는 점수·추천·주의사유 칸에 왜 `_`가 붙었는지 구체적으로 적는다.

가능한 수급부담 원인은 다음 중 하나 이상으로 설명한다.

* 저유동성
* 유상증자
* CB/BW/EB
* 보호예수 해제
* 대량보유/주요주주변동
* 대주주 매도/블록딜
* 자사주처분
* 최대주주변경
* 오버행
* 확인제한

## 3. 공통 작성 방식

첫 열은 `추천/종목`으로 한다.
점수는 별도 열을 만들지 않고 `점수·추천·주의사유` 칸 앞부분에 넣는다.

`가치매수구간`과 `1차 매도/익절가`는 모두 굵은 글씨의 `가격~가격` 범위 형식으로 쓴다.

`분당거래금/유동성`은 `약5.50억/A`처럼 `/분` 없이 표시한다.

`평균거래량·분당거래주식수`는 `약46.6만주·약1,195주/분` 형식으로 쓴다.

`현재위치`는 `저점권반등초입`, `중간권`, `상단권부담`처럼 띄어쓰기 없이 쓴다.

`하루평균 변동폭`은 `약±11,430원(±3.27%)` 형식으로 쓴다.

`기업가치/흐름 평가`와 `점수·추천·주의사유`는 무조건 길게 쓰지 않는다. 실적, 업종흐름, 가격위치, 거래대금, 수급, 뉴스/공시, 기관/애널리스트 동향 중 실제 판단 근거가 있는 내용만 정보밀도 있게 1~2문장으로 작성한다.

## 4. 표별 의미

관종표는 활성 관심종목 종합점검표다.
분석표는 활성 관심종목 빠른 요약표다.
코피표는 코스피 전체 최근 3개월 중기 가치후보표이며 후보 30개와 ✅ 7개를 찾는다.
코피표1개월은 코스피 전체 최근 1달 가치매수 후보표다.
코닥표는 코스닥 전체 최근 3개월 성장·수급 후보표이며 후보 10개와 ✅ 5개를 찾는다.
코닥표1개월은 코스닥 전체 최근 1달 가치매수 후보표이며 수급부담을 포함한다.
코급표는 코스피 단기급등 후보표이며 단기진입구간, 손절선, 거래대금, 가격탄력 중심으로 본다.
월사이클표는 최근 6개월 반복파동 스윙 후보표다.
단상표는 코스피 초단기 상승 후보표다.
환율약세표는 원화약세 수혜·피해 및 환율민감도 점검표다.
시장상태표는 시장 전체 위험도와 주식 비중 판단표다.

## 6. 설명 섹션 출력 규칙

주식표 아래 설명 섹션은 매주 월요일 첫 주식표 요청 때만 기본으로 붙인다.

같은 주 나머지 표 요청에서는 본표 중심으로 제공한다.

사용자가 “설명도 같이”, “표시의미도”, “항목 설명도”, “명령어 설명도”라고 요청하면 요일과 관계없이 설명 섹션을 붙인다.

설명 섹션 순서는 다음과 같다.

1. 표시 의미
2. 불러올 수 있는 표 명령어와 용도
3. 각 항목 의미 설명

`불러올 수 있는 표 명령어와 용도` 표의 열 순서는 다음과 같다.

명령어 | 분석범위 | 쉽게 말하면 | 무엇을 알고자 할 때 쓰나 | 그 표가 주는 의미 | 실제로 달라지는 분석

A+/A/B/C/D 유동성 등급은 표시 의미 표에 넣지 않고, 각 항목 의미 설명의 `분당거래금/유동성` 항목에서만 설명한다.

`거래활발/가격탄력`에서 박스권이라는 말이 나오면 박스권은 “일정 가격 범위 안에서 오르내리며 뚜렷한 상승·하락 방향이 없는 상태”라고 설명한다.

아래 규칙은 최신 개선형보다 우선하지 않는다.

* 코종표
* V 표시
* 구형 표 항목
* 분할 매수 적정가 중심 표현
* 손절기준 기본 포함 방식
* 현재가 보정 아이콘만 표시하는 방식
* 표 설명 섹션을 매번 붙이는 방식
* 점수 별도 열 방식
