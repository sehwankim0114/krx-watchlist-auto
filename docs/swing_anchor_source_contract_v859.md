# V8.5.9 스윙 앵커 원천·용어설명 계약

## 목적

V8.5.9는 V8.5.7의 260거래일 공식 KRX 장기 일봉 캐시와 기존 V8.5.0 큰 스윙 계산 규칙을 연결한다.

새 스윙 공식을 만들지 않는다. 기존 규칙이 이미 산출하는 큰 스윙 상태와 그 상태의 저점·고점 날짜를 공식 종가에 다시 연결해 **근거자료(source evidence)** 로 저장한다.

## 중요한 구분

`스윙 저점`과 `확정 스윙저점 손절가`는 같은 값이 아니다.

- `swing_trough_date`, `swing_trough_close`: 기존 큰 스윙 상태분류에서 관측된 저점 날짜와 그날의 확정 종가.
- `swing_peak_date`, `swing_peak_close`: 같은 규칙에서 관측된 고점 날짜와 그날의 확정 종가.
- `confirmed_swing_low_stop`: V8.5.9에서도 미계산·빈 값이다.
- `ma20_value`: 손절 주문가격이 아니라 참고선이다.
- 추적손절은 신호·기준가격·근거일 계약이 별도로 확정되기 전까지 생성하지 않는다.

따라서 저점 종가를 손절가로 자동 복사하거나 ATR 배수·임의 %를 적용하지 않는다.

## 큰 스윙 상태

기존 `stock_table_metrics_v850.py`의 `RULE_BASED_3M_EXTREMA_MA20_AND_5D_MOMENTUM_V1` 규칙을 그대로 사용한다.

한글 표시는 다음과 같다.

- `BOTTOM_REBOUND` → 저점반등
- `UPTREND` → 상승중
- `UPTREND_PULLBACK` → 상승중 눌림
- `TOP_DECLINE` → 고점후하락
- `NEW_LOW` → 최근 신저점
- `EARLY_REBOUND_UNCONFIRMED` → 초기반등·확인부족
- `SIDEWAYS_OR_UNCONFIRMED` → 횡보·방향미확인
- `INSUFFICIENT` → 자료부족

이 분류는 과거 확정 일봉의 상태 설명이며 미래 가격방향 예측이 아니다.

## 표 출력용 핵심 용어 설명

향후 주식표 출력에는 `latest/stock_table_metric_glossary_latest.json`의 짧은 설명을 표 아래 각주로 붙인다. 표 셀 자체는 지나치게 길게 만들지 않는다.

필수 설명 대상은 다섯 가지다.

1. 스윙
2. MA5/20/60/120
3. ATR14
4. RS 1M/3M
5. 연속등락

RS는 현재 KOSPI 대비 상대수익률 차이이며 업종 RS와 혼동하지 않는다. ATR14는 예상수익률이 아니다.

## 안전장치

V8.5.9는 다음을 하지 않는다.

- 확정 스윙저점 손절가 계산
- 새로운 추적손절 공식 도입
- 독립 종목 스윙추세분석표 활성화
- 업종 RS 계산
- 실적전망 변화 생성
- 투자종합점수100 생성
- 장기 캐시 종가를 요청시점 현재가 대신 사용
- 기존 큰 스윙 계산식 변경
